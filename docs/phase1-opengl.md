# 阶段 1：现代 OpenGL 渲染器

用 OpenGL 4.5 核心档把「一帧里有哪些 pass」做出来。大约 14–16 周。此阶段不写 Vulkan，也不抽 RHI。状态使用直接状态访问（DSA），不再靠固定管线。

你已经画过三角形、纹理、相机和简单光照。第 1 个 Demo 会很快，后面的阴影和 IBL 会占掉大部分周末。

## 学习目标

- 能组织网格、索引、相机、深度和背面剔除。
- 能在 HDR 缓冲里算光照，再色调映射到屏幕。
- 能做方向光阴影贴图，并说清 acne 和 peter panning 各是哪一类偏差。级联阴影（CSM）在单张贴图稳定之后再加。
- 能实现金属-粗糙度直接光，以及 IBL 的三张预计算纹理：辐照度、预滤波环境贴图、BRDF LUT。
- 能写一个 G-Buffer 光照 pass，并和前向用同一场景对比。
- 能做视锥剔除和实例化，并说清它们少掉的是哪一种 CPU 或提交开销。
- 会用 RenderDoc 看一帧：每个 pass 的输入纹理和输出目标。

## 学习产出

笔记：每个 Demo 一页，写清输入、输出、你调过的一个参数以及画面怎么变。

你自己写的 C++ / OpenGL Demo，建议一个 Demo 一个可执行程序，都要能单独运行：

1. `01_mesh`：立方体或球体，索引缓冲，相机，深度测试。
2. `02_blinn`：方向光、点光、聚光。
3. `03_tonemap`：场景画进浮点颜色缓冲，再做 Reinhard 或 ACES 近似。
4. `04_shadow`：先单张方向光阴影贴图。稳定后再做 3 级 CSM。
5. `05_pbr`：法线贴图、金属-粗糙度、IBL。
6. `06_deferred`：G-Buffer 加光照 pass，并保留一条前向路径做对比。
7. `07_cull`：一批物体，CPU 视锥剔除后用实例化画出来。
8. `reference`：把上面收成一个场景。要求有 glTF 模型、PBR、至少一盏带阴影的方向光、天空或 IBL、色调映射。用按键在前向和延迟之间切换。

`reference` 是阶段验收用的程序。前面的 7 个可以继续留着，方便你回看单个问题。

## 学习安排

一个周末只推进一个主要功能。工作日只修这个功能的编译错误、读对应教程的一节、或看一次 RenderDoc。

- 第 1–2 周：`01_mesh`、`02_blinn`。第 2 周周末用 RenderDoc 确认深度和颜色目标。
- 第 3–4 周：`03_tonemap`。对比「直接画到 8 位目标」和「HDR 再映射」的高光。
- 第 5–7 周：`04_shadow`。第 5–6 周单张贴图，第 7 周 CSM。留一周给 acne。
- 第 8–11 周：`05_pbr`。直接光、法线、IBL 分开提交，不要一个周末全塞进去。
- 第 12–13 周：`06_deferred`。
- 第 14 周：`07_cull`。
- 第 15–16 周：`reference`，抓一帧，按验收写笔记。前面有 Demo 超时，就吃掉这两周，不要跳过 `reference`。

## 验收标准

- `reference` 在你的机器上能稳定跑，场景满足上面的内容要求。
- 你能在 RenderDoc 里指出阴影 pass、主场景 pass、色调映射 pass 各自读哪张纹理、写哪张目标。
- 把阴影 bias 调大、调小，你能说出画面上 acne 和 peter panning 哪一个变严重。
- 前向和延迟在同一相机、同一光源下，主要物体的明暗关系一致。允许透明物体和高光细节有差别，但你要能说出差别从哪来。

## 自测

闭卷 45 分钟，外加打开你自己的抓帧讲 10 分钟。

1. DSA 改变的是状态记在谁身上？举一个「改这个纹理的过滤，不会误伤另一张纹理」的例子。
2. 阴影矩阵把世界坐标变到哪几个空间？比较发生在什么数值上？
3. 多边形偏移、常量 bias、画背面进阴影贴图，各自更偏向压 acne 还是 peter panning？
4. IBL 三张纹理里，哪一张随粗糙度选 mip，哪一张和视线、粗糙度有关但和方向无关？
5. G-Buffer 你选了哪些通道？如果法线只存 8 位，高光会出什么问题？
6. 视锥剔除发生在 CPU 还是 GPU？实例化少掉的是顶点数据还是绘制提交？

抓帧口述要能跟着调用顺序走完 `reference` 的一帧。卡在「这张纹理谁写的」上，就还没过。
