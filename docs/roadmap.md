# 学习计划总览

目标：能独立讲清实时渲染，并在 Windows 上用 C++ 把同一套画面跑在 **OpenGL 4.5、Vulkan 1.3、Direct3D 12**。不做编辑器。Direct3D 11 只用来对照「提交绘制时状态从哪来」，不作为第三个后端。

## 时间假设

你还在职，每天学习时间不多。全计划按下面的节奏估，某周加班就整周顺延：

- 工作日：1 小时。用来看一节课、改一个已经在写的 Demo，或者把昨天的报错看懂。
- 周末：连续 3–4 小时。用来把本周 Demo 跑通，并写复盘。
- 一周合计大约 8–10 小时。
- 一个 Demo 如果连续两个周末还没跑通，停下来把现象写进笔记，缩小问题，不同时开下一个。

粗算大约一年出头。阶段 1 和阶段 4 最长，不要靠挤工作日的睡眠去追。

## 顺序

1. 图形学概念先在 OpenGL 里做懂。Vulkan / Direct3D 12 的样板代码很长，不适合同时学 PBR。
2. 显式 API 左右手对照。学的是同步、资源状态和绑定。
3. RHI 放在两个显式 API 都能画出贴图三角形之后。公共接口只包后端差异。

每一阶段的计划都留着验收和自测。每周的材料记录和自己写的总结放在 [../notes](../notes)。Demo 放在 [../code](../code)。

## 各阶段一句话

- 阶段 0：能画出顶点从模型空间到屏幕的路径，并用 C++ 验证投影和软光栅。
- 阶段 1：一个 glTF 场景，带 PBR、方向光阴影、IBL、色调映射；RenderDoc 里能指出每个 pass。
- 阶段 2：Vulkan 和 Direct3D 12 各有清屏、三角形、MVP、贴图、离屏、一次 compute。
- 阶段 3：一份 HLSL，启动参数切换三个 API，画面是同一个贴了纹理的立方体。
- 阶段 4：同一个 glTF 场景在三个 API 下画面一致，包含前向 PBR、阴影、IBL、色调映射。
- 阶段 5：能用自己的抓帧讲阴影瑕疵、G-Buffer、同步错误和多帧并行。

详细的目标、Demo 清单、周安排、链接、验收和自测都在对应的阶段计划里。阶段 0 的验收通过后再开阶段 1，后面同理。
