# 学习笔记

阶段计划在 [../docs](../docs)。这里记每一周实际学过的材料和你自己的总结。

## 目录

```text
notes/
  README.md
  record-template.md
  review-template.md
  W01-坐标空间/
    record.md
    review.md
    images/
  W02-透视投影/
    record.md
    review.md
    images/
```

一周一个目录，名字用 `Wxx-知识点`，例如 `W01-坐标空间`、`W05-阴影贴图`。`Wxx` 按学习顺序编号。截图放在该周的 `images/`。

- [record-template.md](record-template.md)：笔记型记录。按顺序贴本周看过的内容，可以是 AI 整理、视频截图、笔记摘抄。
- [review-template.md](review-template.md)：周末写的总结和复盘。只用自己的话，不把记录再贴一遍。

把两份模板复制到该周目录，改名为 `record.md` 和 `review.md`。对应程序放在 [../code](../code)。

计划文档末尾的「还没搞懂」只保留仍然挡路的问题。总结写完后，把要长期留下的几条抄进 `docs` 里对应阶段的文末。
